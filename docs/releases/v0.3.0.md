# CPC Validation v0.3.0

This release establishes the first generic parity-constraint compiler and benchmark framework for the CPC Validation research prototype.

Version 0.3 transforms the project from a fixed XOR demonstrator into a reusable compiler infrastructure capable of compiling arbitrary parity-constraint benchmark descriptions into executable ngspice circuits, validating them against an independent logical reference implementation, and measuring compiler resource growth.

- generic parity-constraint representation;

Deterministic benchmark generation for

- chain families;
- cycle families;
- star families; and
- random parity systems.

The random generator guarantees that every declared variable participates in at least one constraint and produces reproducible benchmark families from a fixed random seed.

## Scope

The current compiler intentionally uses exhaustive existential enumeration.

For a benchmark with

```
k internal variables
```

the compiler generates

```
2^k candidate sources.
```

Accordingly, Version 0.3 is intended as a correctness-oriented research compiler rather than a scalable SAT implementation.

No claim of polynomial complexity is made.

No claim of practical large-scale SAT solving is made.

The release demonstrates

- correctness of generic compilation;
- answer-independent circuit generation;
- benchmark reproducibility;
- automated validation; and
- compiler resource measurement.

## Reproduction

Clone the repository

```bash
git clone https://github.com/GridSAT/cpc-validation.git
cd cpc-validation
git checkout v0.3.0
```

Create the environment

```bash
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -r requirements-lock.txt
```

Run the complete validation

```bash
python -m pytest -q

python validate.py --full
```

Expected result

```
Status: PASS
Validation profile: full
Steps passed: 10/10
Steps failed: 0
```
