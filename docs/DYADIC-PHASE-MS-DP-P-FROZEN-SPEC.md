## 2. Mathematical setting

Let \(N\) be an odd composite integer and let \(\gcd(a,N)=1\). Define

\[
r=\operatorname{ord}_N(a),\qquad
\theta_s=\frac{s}{r}\in\mathbb T:=\mathbb R/\mathbb Z.
\]

On an orbit eigenstate \(|u_s\rangle\),

\[
U_a|u_s\rangle=e^{2\pi i\theta_s}|u_s\rangle.
\]

For each dyadic scale \(j\geq0\), compile

\[
c_j=a^{2^j}\bmod N
\]

by repeated modular squaring, and define

\[
U_{c_j}=U_a^{2^j}.
\]

Therefore

\[
U_{c_j}|u_s\rangle
=
e^{2\pi i\,2^j\theta_s}|u_s\rangle.
\]

Define the wrapped local phase

\[
\phi_j:=2^j\theta_s\pmod 1.
\]

No order \(r\), sector \(s\), factor of \(N\), expected rational phase, or
expected peak enters compilation, preparation, execution, or operational
inference.

## 3. Open-system channel

For a probe associated with scale \(j\),

\[
H_j
=
g_j\left(
\sigma_j^+\otimes U_{c_j}
+
\sigma_j^-\otimes U_{c_j}^{\dagger}
\right),
\qquad
L_j=\sqrt{\Gamma_j}\,\sigma_j^-\otimes I.
\]

All dyadic observables are functions of the same modular-multiplier spectral
projectors. Hence the same-sector/QND condition remains mandatory:

\[
[H_j,I\otimes P_s]=0,\qquad
[L_j,I\otimes P_s]=0.
\]

The retained data register is prepared once per phase-estimation trial. Probe
reset is not data-register reinitialization. All local phase records in one
trial must refer to one conserved latent sector.

DP-P remains the primary architecture. DP-S remains a separately accounted
resource variant and must not be silently substituted.

## 4. Single-sector reduction

Within a fixed sector,

\[
H_\phi
=
g\left(
e^{2\pi i\phi}\sigma^+
+
e^{-2\pi i\phi}\sigma^-
\right).
\]

With \(R_\phi=\exp(i\pi\phi\sigma_z)\),

\[
H_\phi=R_\phi H_0R_\phi^\dagger,
\]

while the dissipator generated by \(\sigma_-\) is invariant under the same
phase rotation. Thus all single-sector Liouvillians are unitarily equivalent
and have the same spectrum. The local measurement problem is therefore
uniform in \(\phi\) and, in the ideal canonical profile, uniform in the dyadic
index \(j\); only the wrapped phase changes.

For the existing canonical choice

\[
g=\frac{\Gamma}{\sqrt8},
\]

the independently derived stationary coherence is

\[
\langle\sigma_-\rangle_{\rm ss}
=
-\frac{2ig\Gamma}{\Gamma^2+8g^2}e^{2\pi i\phi}
=
-\frac{i}{\sqrt8}e^{2\pi i\phi}.
\]

Its magnitude does not shrink with \(N\), \(r\), \(s\), or \(j\) in the ideal
single-sector model.

The unconditional optical-Bloch deviation generator has nonzero decay modes

\[
-\frac{\Gamma}{2},\qquad
-\frac{3\Gamma}{4}\pm i\frac{\sqrt7\,\Gamma}{4}
\]

at \(g=\Gamma/\sqrt8\). The unconditional single-sector Lindbladian gap is
therefore

\[
\Delta_{\rm L}=\frac{\Gamma}{2}.
\]

This gap is a deterministic mixing fact. By itself it is not yet a
nonasymptotic concentration theorem for the conditioned measurement record.

Photon counting remains phase-blind in this canonical model. The local gate
requires referenced phase-sensitive readout.

## 5. MS-DP-P scale family

Replace the failed fixed scale set \(j=(0,1,2)\) by

\[
j=0,1,\ldots,J
\]

with

\[
J=O(\log N).
\]

The compiled constants satisfy

\[
c_0=a\bmod N,\qquad
c_{j+1}=c_j^2\bmod N,
\]

so compilation requires \(O(J)=O(\log N)\) modular squarings on
\(O(\log N)\)-bit integers.

The ideal DP-P bank uses one retained data register and \(J+1\) probe/reference
channels. Since \(U_{c_j}\) are powers of the same \(U_a\),

\[
[U_{c_j},U_{c_k}]=0.
\]

With separate probe Hilbert spaces,

\[
[H_j,H_k]=0
\]

for the ideal bank. This algebraic commutation supports parallel interrogation;
it does not establish a physical native implementation.

## 6. Constant-precision local estimator contract

Each scale produces a record-only estimate

\[
\widehat\phi_j\in\mathbb T
\]

of

\[
\phi_j=2^j\theta\pmod1.
\]

Freeze a constant

\[
0<\delta<\frac16.
\]

The local event is

\[
E_j=
\left\{
d_{\mathbb T}(\widehat\phi_j,\phi_j)\leq\delta
\right\}.
\]

The operational estimator may use a continuous likelihood or a fixed local
grid of size \(O(1/\delta)\). Because \(\delta\) is independent of \(N\), a
local constant-size grid is admissible. A global \(O(N^2)\) phase grid is not
part of MS-DP-P.

Known \(r,s\), rational-sector tables, expected peaks, or truth-selected branch
choices are forbidden in operational local inference.

## 7. Multiscale unwrapping theorem

### Theorem E0.1 — deterministic branch unwrapping

Assume \(E_0,\ldots,E_J\) all hold with \(\delta<1/6\).

Set

\[
\widehat\theta_0=\widehat\phi_0.
\]

For \(j\geq1\), choose compatible real representatives
\(\widetilde\theta_{j-1}\) and \(\widetilde\phi_j\in[0,1)\), and define

\[
k_j=
\operatorname{round}
\left(
2^j\widetilde\theta_{j-1}-\widetilde\phi_j
\right),
\]

then

\[
\widehat\theta_j
=
\frac{\widetilde\phi_j+k_j}{2^j}\pmod1.
\]

If

\[
d_{\mathbb T}(\widehat\theta_{j-1},\theta)
\leq
\frac{\delta}{2^{j-1}},
\]

then the predicted lifted phase differs from the correct integer branch by at
most \(2\delta\), and the new local phase estimate contributes at most another
\(\delta\). Hence the integer-rounding error is bounded by \(3\delta<1/2\), so
the correct branch is unique.

Inductively,

\[
\boxed{
d_{\mathbb T}(\widehat\theta_J,\theta)
\leq
\frac{\delta}{2^J}.
}
\]

No search over \(2^j\) branches is required; one nearest-integer operation is
performed per scale.

### Corollary E0.2 — POINT precision with logarithmically many scales

The frozen POINT condition is

\[
d_{\mathbb T}(\widehat\theta_J,\theta)
<
\frac{1}{2N^2}.
\]

It suffices to choose

\[
2^J>2\delta N^2.
\]

Therefore

\[
J_\star
=
\min\left\{J\in\mathbb N:2^J>2\delta N^2\right\}
=
2\log_2N+O(1),
\]

and hence

\[
\boxed{J_\star=O(\log N).}
\]

For the prospective convenience value \(\delta=1/8\),

\[
2^J>\frac{N^2}{4}.
\]

For \(N=15\), this sufficient theorem gives \(J=6\). This is not an empirical
claim that seven channels are necessary; it is a sufficient architecture
bound.

## 8. Failure-budget theorem

Let

\[
\Pr(E_j^c)\leq\beta_j.
\]

No independence between channels is required for the union bound:

\[
\Pr\left(
d_{\mathbb T}(\widehat\theta_J,\theta)
>
\frac{\delta}{2^J}
\right)
\leq
\sum_{j=0}^{J}\beta_j.
\]

For a global local-estimation budget \(\beta\), the equal allocation

\[
\beta_j=\frac{\beta}{J+1}
\]

is admissible.

This is an error-allocation theorem only. It does not establish the
single-channel observation time needed to achieve \(\beta_j\).

## 9. E1 local-channel cost gate

The next gate is a uniform single-channel finite-time bound.

### E1 contract

A local referenced estimator passes E1 only if it establishes, under a frozen
instrument and nuisance model, constants independent of \(N,j,\phi\) such that

\[
\Pr_\phi\left(
d_{\mathbb T}(\widehat\phi_T,\phi)>\delta
\right)
\leq B(T,\delta),
\]

with \(T_{\rm loc}(\delta,\beta_j)\) polynomial in the input length and
confidence parameter.

Two sufficient proof routes are allowed.

### Route E1-A — uniform mean-square concentration

If

\[
\sup_\phi
\mathbb E_\phi
\left[
d_{\mathbb T}(\widehat\phi_T,\phi)^2
\right]
\leq
\frac{C_{\rm loc}}{\Gamma T},
\]

with \(C_{\rm loc}\) independent of \(N,j,\phi\), then

\[
\Pr(E_j^c)
\leq
\frac{C_{\rm loc}}{\Gamma T\delta^2}.
\]

With \(\beta_j=\beta/(J+1)\),

\[
T
\geq
\frac{C_{\rm loc}(J+1)}
{\Gamma\delta^2\beta}.
\]

For fixed \(\delta,\beta,\Gamma\),

\[
T=O(J)=O(\log N).
\]

For ideal DP-P, simultaneous elapsed observation time is therefore
\(O(\log N)\) under this sufficient bound, while aggregate channel-time is
\(O((\log N)^2)\).

### Route E1-B — uniform exponential concentration

A stronger admissible result is

\[
\Pr(E_j^c)
\leq
C_0\exp(-C_1\Gamma T\delta^2),
\]

with constants independent of \(N,j,\phi\). Then

\[
T
\geq
\frac{1}{C_1\Gamma\delta^2}
\log\frac{C_0(J+1)}{\beta}.
\]

For fixed global \(\beta\),

\[
T=O(\log\log N).
\]

If \(\beta=N^{-c}\), then \(T=O(\log N)\).

E1-B is desirable but not required for polynomial scaling. E1-A is sufficient.

### Established versus open

Established deterministically for the ideal single-sector generator:

1. phase covariance of the local Liouvillian;
2. nonzero stationary phase contrast at \(g=\Gamma/\sqrt8\);
3. phase-independent unconditional gap \(\Gamma/2\);
4. no intrinsic \(j\)-dependence in the reduced local generator;
5. the need for referenced phase-sensitive readout.

Not yet established:

1. a rigorous finite-time value of \(C_{\rm loc}\);
2. a rigorous exponential-concentration pair \(C_0,C_1\);
3. robustness of either bound to the declared calibration/nuisance model;
4. physical detector bandwidth, drift, correlated-noise, or crosstalk scaling;
5. native synthesis cost of \(H_j\).

The Lindbladian gap alone must not be cited as if it proved E1-A or E1-B.

## 10. Inference complexity

MS-DP-P forbids rescuing POINT precision by a global
\(M=\Theta(N^2)\) likelihood grid.

Local inference is constant precision. The branch recursion performs one
constant-size local inference plus one integer-rounding operation per scale.
Ignoring the internal cost of the frozen local likelihood engine, the
multiscale orchestration cost is

\[
O(J)=O(\log N).
\]

The existing POINT / fixed-\(k\) BE downstream reconstruction remains a
separate P4 layer. MS-DP-P does not change its radius, certificate rules,
freshness requirements, or wrong-acceptance semantics.

## 12. Circuit-mediated reference versus native realization

For each compiled \(c_j\),

\[
W_{c_j}
=
|g\rangle\langle g|\otimes I
+
|e\rangle\langle e|\otimes U_{c_j}
\]

gives

\[
H_j
=
g_j W_{c_j}(X_j\otimes I)W_{c_j}^\dagger.
\]

Because reversible modular multiplication has polynomial circuit complexity
and \(J=O(\log N)\), MS-DP-P has a polynomial circuit-mediated reference
description.

This does not prove a CPC-native implementation. Repeated squaring computes
\(c_j\); it does not synthesize the Hamiltonian.
