## Future publication safeguards

The root CITATION.cff declares the individual author and version-specific DOI.
The root .zenodo.json declares the same creator and a distinct Sponsor role;
it deliberately omits fixed version/DOI/date fields so a future release does not
reuse an old version DOI. Zenodo gives .zenodo.json precedence over CFF, so its
description, keywords and MIT license mirror the branch's existing metadata.

Run python verify_authorship_metadata.py and the complete validate.py --full
profile. The focused regression rejects organizational creator/author assignment,
ORCID loss, DOI substitution and sponsor-role tampering while allowing copyright,
affiliation and third-party bibliography entries. This is metadata validation,
not a new scientific or hardware qualification.
